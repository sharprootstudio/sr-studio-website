## 🛠️ Local Development

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/sharprootstudio/sr-studio-website.git
cd sr-studio-website

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run locally at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
